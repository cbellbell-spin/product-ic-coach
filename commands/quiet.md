description: Toggle command suggestions on or off. Command prompts normally appear at natural transition points. When quiet is active, suppress all prompts until /quiet is invoked again.
---

Toggle the command suggestion behavior:

- If suggestions are currently active, suppress them. You will not see command prompts at transition points until you re-enable with /quiet.
- If suggestions are currently suppressed, re-enable them. Command prompts will resume at natural transition points.

Acknowledge the toggle state briefly and continue with whatever the session needs next.
